GAME MECHANICS:
- Canvas-based fishing game using HTML5 Canvas
- A fishing rod at the top center, line hangs down with a hook swinging left-right
- Fish swim across the screen at different depths, each fish has answer text on it
- 4 fish total per question, one per answer option
- Fish labeled with answer options swim left and right at different vertical positions
- Player taps/clicks canvas to CAST the line - hook shoots down quickly
- If hook reaches a fish, it catches it and pulls it up
- Correct fish caught: +100 pts + coin sound
- Wrong fish: -30 pts + fail sound, re-cast needed, fish respawn
- Next question after catching correct fish
- Use pointerdown on canvas for tablet support, touch-action: none
- Line physics: hook swings pendulum style, cast drops down, retract after catch/miss boundary
- Canvas height: 450px inside a wrapper div with question text above

FISH DESIGN:
- Draw fish as simple ellipse with tail triangle using Canvas 2D
- Each fish has answer text drawn inside it
- Correct fish = gold/yellow, wrong fish = blue/teal colors (player doesn't know which is correct until they catch it)
- Fish animate: wiggling movement left and right, wrap around edges
