# Classroom Arcade 教室遊樂園 🎮

這是一個專為課堂複習設計的互動遊戲平台！整合了**大富翁**、**連連看**、**打地鼠**和**尋寶記**四款小遊戲，學生可以藉由玩遊戲複習題庫，而答題的分數與記錄會自動儲存到 Google 試算表。

## 🌟 特色功能

1. **四合一課堂遊戲**：
   - 🎲 **知識大富翁**：經典骰子繞圈遊戲，觸發答題、命運與機會事件。
   - 🧩 **知識連連看**：考驗記憶與反應，將題目卡與正確答案卡進行配對。
   - 🔨 **拼速打地鼠**：在時限內打中帶著正確答案的驚喜地鼠，挑戰連擊加分。
   - 🏴‍☠️ **秘境尋寶記**：以答題解鎖道路，在地圖中避開陷阱尋找終極寶箱。
2. **雲端題庫與成績單**：
   - 題目直接從您的 Google 試算表讀取，方便老師隨時修改。
   - 學生遊玩後的分數與時間會自動上傳到試算表中的「遊戲成績」分頁。
3. **無縫部署**：
   - 採用純 HTML5 / CSS3 / Vanilla JS 開發，無須複雜的建置步驟，可一鍵部署至 Netlify。
   - 內建 **Demo 測試模式**（預設載入趣味百科題目），即使不綁定 API 也能立即體驗！

## 🛠️ 三步驟架構與部署教學

### 第一步：準備您的 Google 試算表

1. 準備您的題庫試算表（或使用已設定好的試算表 `1schm9u2LKrGFMsdQKn1Nd614YoFdov59FjWWSRC0CTQ`）。
2. 請確保題庫工作表（名稱為「**題目**」或第一張工作表）設定如下的兩欄式欄位：
   - **第一欄 (Column A)**：題目 (例如：`光在真空中的傳播速度大約是多少？`)
   - **第二欄 (Column B)**：答案 (例如：`每秒 30 萬公里`)
   - **第三欄 (Column C, 選填)**：解析 (例如：`光速概算為每秒 30 萬公里。` - 用於答題後的詳細說明)
   
*註：為了讓系統能有效從其他題目隨機抽選出錯誤選項（干擾項），您的題庫建議至少要有 4 題以上喔！*

---

### 第二步：部署 Google Apps Script 後端 API

1. 在該 Google 試算表上方選單點選 **「擴充功能」 > 「Apps Script」**。
2. 將本專案中的 [backend/Code.js](file:///c:/Users/user/Desktop/antigravity20260602/backend/Code.js) 代碼完整複製，覆蓋貼入 Apps Script 編輯器中（覆蓋預設的 `myFunction`）。
3. 點選儲存（磁碟圖示）。
4. 點選右上角 **「部署」 > 「新增部署」**：
   - 點選左上角齒輪圖示，確保選擇 **「網頁應用程式 (Web App)」**。
   - **說明**：例如輸入 `Classroom Arcade API v1.0`。
   - **專案執行為**：選擇 **「我 (Me)」**。
   - **誰有存取權**：必須選擇 **「任何人 (Anyone)」**（這樣遊戲前端才能成功發送 API 請求）。
5. 點選 **「部署」**，並在跳出視窗中允許 Google 帳號授權。
6. 部署完成後，複製畫面上顯示的 **「網頁應用程式 URL」** (例如：`https://script.google.com/macros/s/xxxx/exec`)。

---

### 第三步：部署遊戲前端至 Netlify

由於本遊戲是完全靜態的網頁，您可以非常簡單地部署到 Netlify：

#### 方法 A：拖放部署 (極速！)
1. 瀏覽 [Netlify 官網](https://www.netlify.com/) 並登入帳號。
2. 進入 Netlify Dashboard 後，切換到 **Sites** 頁面。
3. 將本專案的根目錄資料夾（包含 `index.html`、`style.css`、`app.js` 與 `games/` 的資料夾）直接拖放到頁面底部的 **"Drag and drop your site folder here"** 上傳區域。
4. 幾秒鐘後即部署完畢！Netlify 會提供您一個專屬的網址。

#### 方法 B：連結 GitHub 自動部署
1. 將本資料夾代碼上傳至您的 GitHub 儲存庫。
2. 在 Netlify 中點選 **"Add new site" > "Import an existing project"**。
3. 選擇 GitHub 並授權，選取該專案的 Repo。
4. Build settings 保持為空（因為無須建置），直接點選 **Deploy** 即可。未來您每次 push 代碼到 GitHub，Netlify 都會自動更新！

## 🎮 學生如何開始遊玩？

1. 打開 Netlify 的部署網址。
2. 點選網頁右上角的 **「設定 (Settings)」** 按鈕（齒輪圖示）。
3. 貼上您在**第二步**中取得的 **Google Apps Script Web App API 網址**，並點選「測試連線並儲存」。
4. 連線成功後，系統會提示已讀取到題庫題目數量，且頂部的「單機測試模式」黃色橫幅會消失。
5. 學生輸入 **班級**、**座號** 與 **姓名**，點選「確認玩家身份」登錄。
6. 遊戲解鎖！點選任一款遊戲的「開始遊戲」即可暢玩。
7. 當遊戲挑戰成功或結束時，分數與答題率將會自動記錄回 Google 試算表新建的 **「遊戲成績」** 分頁中，方便老師彙整與統計！
